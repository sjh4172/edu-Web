# edu-Web

Spring Boot 기반의 웹 서비스 프로젝트입니다.

## 주요 기능

* 회원가입 및 로그인
* 사용자 인증 및 권한 관리
* 게시판 기능
* 데이터베이스 연동
* REST API 기반 백엔드 구현

## 기술 스택

* Java
* Spring Boot
* Spring Security
* MySQL
* Maven

## 프로젝트 구조

```text
edu-Web
├── src/
│   ├── main/
│   └── test/
├── pom.xml
└── mvnw
```

## 실행 환경

* Java 17+
* Spring Boot
* MySQL

## 개발 목적

Spring Boot 기반의 백엔드 개발 및 웹 서비스 구현을 목적으로 진행한 프로젝트입니다.
